## 1. 优化全景

```text
显存维度:
  ├─ 轻量微调: LoRA / QLoRA / GaLore / LISA / Adapter ...
  ├─ 量化: BNB / AWQ / GPTQ / FP8 训练
  ├─ 序列并行: Ulysses / Ring-Attention (长文本)
  ├─ 激活优化: gradient checkpointing / activation cpu offload
  ├─ 注意力: Flash Attention 2/3 / SDPA
  └─ 算子融合: liger-kernel / unsloth
速度维度:
  ├─ 数据: packing（多模态打包提速 100%+）
  ├─ 算子: flash-attn / liger 融合算子
  └─ 分布式: DDP / FSDP / DeepSpeed / Megatron (TP/PP/CP/EP)
```

## 3. GaLore 系列（`swift/optimizers/galore/`）

GaLore：**梯度投影到低秩子空间**，省优化器显存（Adam 状态从 [N,N] 降到 [N,r]）。

```text
galore_projector.py GaLoreProjector (L6)
  ├─ SVD 求正交投影
  ├─ project (L16) / project_back (L51)
  └─ 支持 std / left / right / full 投影
galore/adamw.py AdamW / GaLoreAdamW (L13/L140)
  └─ step 中先 project(grad) 低秩更新再 project_back
galore/adafactor.py GaLoreAdafactor
galore/adamw8bit.py GaLoreAdamW8bit (bnb 8bit 版，条件导入)
galore/utils.py GaloreOptimizerCallback (L222) + GaLoreConfig (L27)
  └─ quantize 走 q_galore (QGaLoreAdamW8bit L202)
```

## 6. loss_scale（`swift/loss_scale/`）

**注意**：v4.0 中此目录并非"loss 缩放防下溢"，而是**上下文损失权重控制**（Agent 训练）：

- `LossScale`（`base.py` L12）：基类，`base_strategy`（default/last_round/all）；
- `is_binary`（L32）：loss_scale 是否仅 0/1；
- `ConfigLossScale`（L139）：从 JSON config 加载权重映射；`ConcatLossScale`（L202）组合策略；
- `agent.py`：`REACTLossScale` / `QwenLossScale` / `HermesLossScale` / `AgentFlanLossScale` / `AlphaUmiLossScale`（L19-33）；
- `utils.py` `calculate_loss_scale`（L7）：按 Agent 响应分段计算权重（arXiv:2309.00986）；
- **显存优化点**：`is_binary_loss_scale=True` 时，`swift/template/base.py` `_encode_context_list`（L1089-1113）把 loss_scale 折叠进 labels（0 处置 -100），**兼容 liger_kernel 并省显存**；非 binary 才额外保存 loss_scale 张量。

## 8. 显存优化工具链

### 8.1 梯度检查点

- `SwiftMixin._prepare_gradient_checkpointing`（mixin.py L930）；
- `dynamic_gradient_checkpointing`（trainers/utils.py L248）：自动给最长 module_list 加 grad ckpt；
- `_fix_gradient_checkpointing`（mixin.py L900）：patch `use_reentrant`。

### 8.2 激活 CPU Offload

`swift/callbacks/activation_cpu_offload.py` `ActivationCpuOffloadCallBack`（L585）：backward 保存激活张量时 offload 到 CPU 省显存。

### 8.3 注意力实现切换

`--attn_impl flash_attn/sdpa/eager`（`AttnImpl`，model/utils.py L27）。

### 8.4 数据打包加速

- `PackingDataset`（binpack best-fit-decreasing / sequential next-fit）；
- 多模态 packing 提速 100%+；
- 流式打包 `IterablePackingDataset`（`packing_interval=128` 滑动）。

### 8.5 量化训练

- BNB 4bit：7B 训练仅需 9GB；
- `--quant_method bnb_4bit` / AWQ / GPTQ / AQLM / HQQ / EETQ 量化模型训练；
- LoRA dispatcher 支持 bnb 8bit/4bit。

## 10. 性能优化速查表

| 目标 | 手段 |
|------|------|
| 省显存（小卡跑大模型） | QLoRA + GaLore + flash-attn + grad ckpt + activation offload |
| 长文本 | Ring-Attention / Ulysses / LongLoRA / packing + padding-free |
| 提速 | flash-attn2/3 + liger 融合算子 + packing + MergedLinear(QKV) |
| MoE 提速 | Megatron TP/EP |
| 多模态 | freeze_vit/freeze_aligner/freeze_llm + 多模态 packing + 分 lr 优化器 |
| 训练稳定性 | loss_scale 上下文权重 + MuonClip max-logits 追踪 |

```text
提速   → liger/flash 融合算子 + MergedLinear + 多模态 packing
```
