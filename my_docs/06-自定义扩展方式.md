## 1. 注册机制全景

ms-swift 采用 **dict 型注册表 + dataclass 元数据** 的注册模式，**没有使用 Python 装饰器语法**（`@register_*`），而是**函数调用式注册**（`register_model(ModelMeta(...))`）。

### 1.1 注册表清单

| 注册表 | 定义位置 | 注册 key | 注册函数 | 取回函数 |
|--------|----------|----------|----------|----------|
| `MODEL_MAPPING` | `swift/model/model_meta.py` L122 | `model_type` | `register_model`（`model/register.py` L31） | `get_matched_model_meta`（L165） |
| `DATASET_MAPPING` | `swift/dataset/dataset_meta.py` L202 | `dataset_name` 或 `(ms_id, hf_id, path)` 元组 | `register_dataset`（`dataset/register.py` L26） | `load_dataset` |
| `TEMPLATE_MAPPING` | `swift/template/register.py` L13 | `template_type` | `register_template`（L16） | `get_template`（L55） |
| `SWIFT_MAPPING` | `swift/tuners/mapping.py` L30 | tuner 类型名 | 直接赋值 | `SwiftModel._prepare_model` |
| `tuners_map` | `swift/tuner_plugin/mapping.py` L6 | tuner 名 | 直接赋值 | `get_supported_tuners` |
| `loss_map` | `swift/loss/mapping.py` L6 | loss 名 | 直接赋值 | `loss_map` |
| `orms` | `swift/rewards/orm.py` L455 | ORM 名 | 直接赋值 | `orms` |
| `prms` | `swift/rewards/prm.py` L153 | PRM 名 | 直接赋值 | `prms` |
| `rm_plugins` | `swift/rewards/rm_plugin.py` L230 | 插件名 | 直接赋值 | `rm_plugins` |
| `callbacks_map` | `swift/callbacks/mapping.py` L9 | 回调名 | 直接赋值 | `callbacks_map` |
| `eval_metrics_map` | `swift/metrics/mapping.py` L10 | 指标名 | 直接赋值 | `eval_metrics_map` |
| `loss_scale_map` | `swift/loss_scale/mapping.py` L7 | 策略名 | 直接赋值 | `get_loss_scale` |
| `optimizers_map` | `swift/optimizers/mapping.py` L9 | 优化器名 | 直接赋值 | `optimizers_map` |
| `MODEL_ARCH_MAPPING` | `swift/model/model_arch.py` L152 | 架构名 | `register_model_arch`（L155） | — |

### 1.2 模型注册示例

```python
# swift/model/register.py L31
def register_model(model_meta: ModelMeta, *, exist_ok: bool = False) -> None:
    model_type = model_meta.model_type
    if not exist_ok and model_type in MODEL_MAPPING:
        raise ValueError(f'The `{model_type}` has already been registered in the MODEL_MAPPING.')
    MODEL_MAPPING[model_type] = model_meta
```

`ModelMeta`（`model_meta.py` L57）关键字段：

```text
model_type        # 模型唯一 ID
model_groups      # 模型 ID 列表（ModelGroup，用于从 model_id 反推 model_type）
loader            # 加载器类（默认 ModelLoader）
template          # 默认模板
model_arch        # 架构
architectures     # 模型类名列表
torch_dtype       # 默认精度
is_multimodal     # 是否多模态
is_reward         # 是否奖励模型
requires          # 版本约束
```

### 1.3 数据集注册示例

```python
# swift/dataset/register.py L26
def register_dataset(dataset_meta: DatasetMeta, *, exist_ok: bool = False) -> None:
    if dataset_meta.dataset_name:
        dataset_name = dataset_meta.dataset_name
    else:
        dataset_name = dataset_meta.ms_dataset_id, dataset_meta.hf_dataset_id, dataset_meta.dataset_path
    DATASET_MAPPING[dataset_name] = dataset_meta
```

`DatasetMeta`（`dataset_meta.py` L174）关键字段：`ms_dataset_id` / `hf_dataset_id` / `dataset_path` / `dataset_name` / `subsets` / `preprocess_func` / `loader` / `tags`。

内置 150+ 数据集通过 `register_dataset_info`（register.py L84）从 `data/dataset_info.json` 批量注册。

## 2. 自定义数据集

### 2.1 最简方式：直接传路径 / JSONL

```bash
swift sft --model Qwen3-8B --dataset ./my_data.jsonl
```

JSONL 格式（一行一条）：

```json
{"messages": [{"role": "user", "content": "你好"}, {"role": "assistant", "content": "你好！"}]}
```

或 sharegpt / alpaca / openai 格式（由 `AutoPreprocessor` 自动识别）。

### 2.2 注册为内置数据集

1. 定义 `DatasetMeta`，指定 `ms_dataset_id` / `hf_dataset_id` / `dataset_path`；
2. 指定 `preprocess_func` 或 `loader`（自定义 `BaseDatasetLoader` 子类）；
3. 调用 `register_dataset(dataset_meta)`；
4. 命令行用 `--dataset my_dataset`。

### 2.3 自定义 Preprocessor

实现 `RowPreprocessor` 子类（`swift/dataset/preprocessor/core.py` L28），把原始行转换为标准行（messages/images/videos...）。示例参考 `swift/dataset/dataset/llm.py`、`mllm.py` 的 60+ 个子类。

## 3. 自定义模型

### 3.1 步骤

```text
1. 定义 ModelMeta（model_type、model_groups、loader 等）
2. register_model(model_meta)
3. （可选）自定义 ModelLoader 子类，覆写钩子:
     get_config (L247) / get_processor (L259) / get_model (L270) / _postprocess_model (L342)
4. （可选）多模态: 在 model_arch.py 注册 MODEL_ARCH_MAPPING + MultiModelKeys
```

### 3.2 `ModelLoader` 钩子（`swift/model/register.py` L160）

```text
ModelLoader (L160)
  ├─ get_config (L247)          # 读取模型 config
  ├─ get_processor (L259)       # 读取 processor/tokenizer
  ├─ get_model (L270)           # 构建模型
  ├─ _postprocess_model (L342)  # 后处理（如 LoRA 加载）
  └─ load (L470)                # 总入口
子类:
  SentenceTransformersLoader (L485)   # Embedding 模型
  RewardModelLoader (L508)            # 奖励模型
```

### 3.3 多模态模型组织

`MultiModelKeys`（`model_arch.py` L136）定义模块路径：

```python
ModelKeys.language_model / aligner / vision_tower / generator
```

按此路径可单独控制（freeze_vit / freeze_aligner / freeze_llm、MultimodalOptimizerCallback 分 lr）。

## 4. 自定义模板

### 4.1 注册

```python
# swift/template/register.py L16
register_template(TemplateMeta(...))
```

`TemplateMeta` 包含 `template_type`、`prefix`（system prompt 等）、`default_system` 等。

### 4.2 关键方法（`swift/template/base.py`）

- `encode`：消息 → input_ids/labels；
- `compute_sft_loss`：SFT loss 计算；
- `_encode_context_list`：上下文编码（loss_scale 折叠）。

40+ 内置模板在 `swift/template/template.py`（qwen、llama、glm、internlm、kimi 等）。自定义时找一个最接近的模板子类化。

## 5. 自定义 Tuner

### 5.1 方式一：用 peft 生态

AdaLoRA / BOFT / Vera / OFT / LoHa / LoKr / PrefixTuning 已通过 `swift/tuners/peft.py` 兼容，直接 `--tuner_backend adalora` 等即可。

### 5.2 方式二：实现 Swift tuner

1. 实现 `SwiftAdapter` 子类（`swift/tuners/utils.py` L278）：`prepare_model` / `activate_adapter` / offload；
2. 实现 Config dataclass（继承 `SwiftConfig`）；
3. 在 `SWIFT_MAPPING`（`swift/tuners/mapping.py` L30）注册；
4. 在 `swift/tuners/__init__.py` 导出。

---

## 6. 自定义奖励函数

### 6.1 签名约定

```python
def my_reward(completions: List[str], **kwargs) -> List[float]:
    # kwargs 含 solution / ground_truths / infer_requests / response_token_ids / trainer_state 等
    return [1.0 if "答案" in c else 0.0 for c in completions]
```

### 6.2 使用

```bash
swift rlhf --rlhf_type grpo --reward_funcs my_reward
```

或 `--reward_funcs ./my_reward.py`（文件方式）。异步奖励函数也支持（`_is_async_reward` 检测，`asyncio.gather` 并发）。

### 6.3 奖励模型插件（`swift/rewards/rm_plugin.py`）

- 实现 `RMPlugin` 子类，注册进 `rm_plugins`；
- `default`：判别式 RM（logits[:,0]）；`genrm`：生成式 LLM-judge。

## 7. 自定义参数

通过 dataclass 多重继承扩展：

```python
from swift.arguments import SftArguments

@dataclass
class MyArguments(SftArguments):
    my_param: int = 42

# 命令行: --my_param 100
```

`BaseArguments`（base_args.py L47）作为根，`parse_args` 自动合并所有字段。

---

## 8. 自定义 Loss / 训练器

### 8.1 自定义 Loss

1. 继承 `BaseLoss`（`swift/loss/base.py` L10），实现 `__call__(outputs, labels, *, num_items_in_batch, loss_scale, **kwargs)`；
2. 注册进 `loss_map`（`swift/loss/mapping.py` L6）；
3. `--loss_type my_loss` 使用。

### 8.2 自定义 Trainer

1. 继承对应 trainer（如 `Seq2SeqTrainer`）或 mixin；
2. 在 `TrainerFactory.TRAINER_MAPPING`（`swift/trainers/trainer_factory.py` L13）注册；
3. 在 `TRAINING_ARGS_MAPPING`（L30）注册对应训练参数类。

## 9. 自定义回调 / 指标 / 优化器

| 扩展点 | 注册表 | 使用 |
|--------|--------|------|
| 回调 | `callbacks_map`（callbacks/mapping.py L9） | `--callbacks xxx` |
| 评估指标 | `eval_metrics_map`（metrics/mapping.py L10） | `--metric xxx` |
| 优化器 | `optimizers_map`（optimizers/mapping.py L9） | `--optimizer xxx` |
| loss_scale 策略 | `loss_scale_map`（loss_scale/mapping.py L7） | `--loss_scale xxx` |

## 10. 扩展开发清单

| 想做什么 | 改哪里 |
|----------|--------|
| 新数据集 | `register_dataset` + （可选）RowPreprocessor 子类 |
| 新模型 | `register_model` + ModelLoader 钩子 |
| 新模板 | `register_template` + Template 子类 |
| 新 Tuner | SwiftAdapter 子类 + SWIFT_MAPPING |
| 新奖励函数 | 函数 + `--reward_funcs` |
| 新 Loss | BaseLoss 子类 + loss_map |
| 新 Trainer | trainer 子类 + TRAINER_MAPPING |
| 新参数 | dataclass 继承 |
| 新回调/指标/优化器 | 各自注册表 |

---

## 11. 一句话总结

```text
注册机制 = dataclass 元数据 + 全局 dict 注册表 + 函数调用注册
扩展方式 = 找到对应注册表 → 实现子类/函数 → 注册 → 命令行使用
```
