## 1. 参数系统：dataclass 的多重继承体系

### 1.1 总览

ms-swift 的参数全部是 **dataclass**，通过**多重继承**组合成"金字塔"：

```text
                    BaseArguments (base_args/base_args.py L47)
                     ├─ GenerationArguments (base_args/generation_args.py L12)
                     ├─ QuantizeArguments (base_args/quant_args.py L11)
                     ├─ DataArguments (base_args/data_args.py L12)
                     ├─ TemplateArguments (base_args/template_args.py L13)
                     ├─ ModelArguments (base_args/model_args.py L17)
                     └─ RayArguments
                              │
                              ▼
TunerArguments (tuner_args.py L12)          # 各 tuner 专属参数
    │
    ▼
SftArguments (sft_args.py L124) = SwanlabArguments + TunerArguments + BaseArguments + Seq2SeqTrainingArguments
    │
    ▼
RLHFArguments (rlhf_args.py L175) = TeacherModelArguments + GRPOArguments + PPOArguments
                                   + RewardModelArguments + SftArguments
```

### 1.2 核心参数类字段速查

| 参数类 | 文件 | 关键字段 |
|--------|------|----------|
| `ModelArguments` | `base_args/model_args.py` L17 | `model`、`model_type`、`task_type`、`torch_dtype`、`attn_impl`、`rope_scaling`、`device_map`、`max_model_len`、`init_strategy` |
| `DataArguments` | `base_args/data_args.py` L12 | `dataset`、`val_dataset`、`cached_dataset`、`streaming`、`dataset_shuffle`、`shuffle_buffer_size`、`interleave_prob`、`split_dataset_ratio`、`columns`、`strict`、`remove_unused_columns` |
| `TemplateArguments` | `base_args/template_args.py` L13 | `template`、`system`、`max_length`、`truncation_strategy`、`max_pixels`、`padding_free`、`loss_scale`、`use_chat_template`、`template_backend` |
| `GenerationArguments` | `base_args/generation_args.py` L12 | `max_new_tokens`、`temperature`、`top_k`、`top_p`、`num_beams`、`stream`、`stop_words` |
| `QuantizeArguments` | `base_args/quant_args.py` L11 | `quant_method`、`quant_bits`、`bnb_4bit_*`、`hqq_axis` |
| `TunerArguments` | `tuner_args.py` L12 | `lora_rank`、`lora_alpha`、`lora_dropout`、`target_modules`、`freeze_parameters`、`init_weights`（约 50 个字段） |
| `RLHFArguments` | `rlhf_args.py` L175 | `rlhf_type`、`beta`、`ref_model`、`max_completion_length`、`loss_type`、`reward_funcs`、`reward_weights` |

### 1.3 RLHF 参数子类（`swift/arguments/rlhf_args.py`）

```text
TeacherModelArguments (L41)   # GKD / OPD-RL 的 teacher 模型参数
PPOArguments (L94)            # PPO 参数（value model 等）
GRPOArguments (L130)          # GRPO 参数（num_generations、max_completion_length 等）
RewardModelArguments (L17)    # reward model 参数
RLHFArguments (L175)          # 总参数，rlhf_type 决定使用哪个 trainer
```

### 1.4 训练参数（`swift/trainers/arguments.py`）

- `TrainArgumentsMixin`（L17）：训练超参，继承 `HfTrainingArguments` / `HfSeq2SeqTrainingArguments`；
- `TrainingArguments`（L287）、`Seq2SeqTrainingArguments`（L295）；
- `report_to`（L145）默认 `['tensorboard']`，可 `--report_to wandb`；
- `resume_only_model`（L161）：恢复时只加载模型权重。

## 2. 消息数据结构：纯 dict + 类型别名

**重要**：ms-swift v4.0 中对话消息**没有独立的 dataclass**，统一用 dict + 类型别名（`swift/template/utils.py` L11-17）：

```python
Message = Dict[str, Union[str, List, List[int], None]]
Messages = List[Message]
```

### 2.1 role 合法取值

`swift/dataset/preprocessor/core.py` `RowPreprocessor._check_messages`（L68-83）：

```text
role 合法集合: {system, user, tool_call, tool_response, tool, assistant}
每消息字段仅保留: role / content / loss / loss_scale (L75)
```

### 2.2 多模态字段

`_cast_mm_data`（L86-106）：多媒体字段是**行级顶层字段** `images/audios/videos`（及 `rejected_images`），image 结构为 `{'bytes': None, 'path': str}`。

`_pair_keys`（L25）：`['messages', 'images', 'videos', 'audios', 'tools', 'objects']`，`RowPreprocessor.standard_keys`（L29）扩展了 `rejected_/positive_/negative_` 前缀键、`rejected_response`、`label`、`teacher_prompt`、`chat_template_kwargs` 等。

### 2.3 示例消息

```json
[
  {"role": "system", "content": "You are a helpful assistant."},
  {"role": "user", "content": "What is 2+2?", "images": [{"path": "a.png"}]},
  {"role": "assistant", "content": "4"}
]
```

## 3. 数据集数据结构：Row → Preprocessed → Encoded

### 3.1 数据集注册元数据 `DatasetMeta`（`swift/dataset/dataset_meta.py` L174）

关键字段：`ms_dataset_id` / `hf_dataset_id` / `dataset_path` / `dataset_name` / `subsets` / `preprocess_func` / `loader` / `tags`。

### 3.2 加载流程 `DatasetLoader`（`swift/dataset/loader.py` L22）

```text
DatasetLoader.load_dataset (L224)
  ├─ 解析 DatasetSyntax: "dataset:subset#sample" (dataset_syntax.py L14)
  ├─ _load_dataset_path (L46): 本地 jsonl/csv/json/txt
  ├─ _load_repo_dataset (L71): ModelScope / HF hub，重试 + to_iterable_dataset()
  ├─ concat / interleave / shuffle
  └─ self-cognition 注入 dataset 路由列 (L217)
```

### 3.3 预处理类体系（`swift/dataset/preprocessor/core.py`）

```text
RowPreprocessor (L28)                    # 基类：_check_messages / _cast_mm_data
  ├─ ResponsePreprocessor (L372)         # 旧格式 query/response/history → messages
  │    └─ AlpacaPreprocessor (L410)      # instruction/input/output
  ├─ MessagesPreprocessor (L437)         # sharegpt/openai/anthropic/swift 四种格式归一化
  │    ├─ OpenAIMessagesPreprocessor (L693)
  │    └─ AnthropicMessagesPreprocessor (L699)
  └─ AutoPreprocessor (L713)             # 按 dataset features 自动选择
```

具体数据集 Preprocessor 子类（60+ 个）在 `swift/dataset/dataset/`：
- `llm.py`：28 个（`SelfCognitionPreprocessor` L882、`HHRLHFPreprocessor`、`FireflyPreprocessor` 等）；
- `mllm.py`：32 个（`ShareGPT4VPreprocessor`、`Qwen3TTSPreprocessor`、`RefCOCOPreprocessor` 等）。

### 3.4 编码后的训练样本结构

经过 `template.encode` 后，每条样本是 dict，包含：

```text
input_ids: List[int]         # 输入 token
labels: List[int]            # 标签（SFT 时 assistant 部分为目标，其余 -100）
loss_scale: List[float]      # 可选，逐 token 权重
images / videos / audios:    # 多模态原始数据
position_ids / attention_mask / cu_seqlens:  # padding-free / SP 场景
```

### 3.5 惰性编码与打包

- `LazyLLMDataset`（`swift/dataset/utils.py` L57）：惰性编码并跳过坏样本；
- `PackingDataset`（`packing.py` L50）：非流式打包（binpack / sequential）；
- `IterablePackingDataset`（`packing.py` L137）：流式打包；
- `IndexedDataset`（`indexed_dataset.py` L95）：二进制索引数据集（`.bin`+`.idx`），mmap 读取。

## 4. RL 样本与批次结构（`swift/rl_core/data.py`）

这是 GRPO / GKD 等 RL 训练的专用数据结构，区别于 SFT 的 dict 行。

### 4.1 `OnPolicySample`（L27）

一条 on-policy rollout 轨迹（collate 前、逐样本）：

```python
@dataclass
class OnPolicySample:
    messages: List[Dict]                    # 标准键
    images / videos / audios: List[Any]     # 多模态
    tools / objects
    extra: Dict[str, Any]                   # dataset 透传列（solution/target...）
    prompt_id / request_id: str             # 标识
    response_token_ids: List[List[int]]     # rollout 输出
    response_loss_mask: List[List[int]]
    rollout_logprobs: List[List[float]]     # 重要性采样
    finish_reason: Optional[str]            # 'length' 表示截断
    add_eos: bool
    rollout_infos: Dict[str, Any]
    routed_experts: Optional[Any]           # R3 router replay
    encoded: Optional[Dict[str, Any]]       # template.encode 输出
    teacher_prompt / teacher_messages       # OPSD（GKD/OPD-RL）
```

关键方法：

| 方法 | 行号 | 作用 |
|------|------|------|
| `from_row` | L151 | 从 dataloader 行构建（已知键映射字段，其余进 extra，深拷贝） |
| `to_template_dict` | L177 | 重建 template.encode 的输入 |
| `to_reward_row` | L128 | 重建奖励函数输入（extra 展平到顶层） |
| `apply_rollout_output` | L195 | 合并 rollout 输出（单轮/多轮自动判定） |
| `to_infer_request` | L244 | 构造 rollout 引擎请求 `RolloutInferRequest` |
| `build_teacher_view` | L84 | OPSD teacher 视图（teacher_prompt 替换最后 user） |

### 4.2 `GRPOSample`（L298）

```python
@dataclass
class GRPOSample(OnPolicySample):
    rewards: Optional[List[Optional[float]]]    # 奖励镜像
    advantages: Optional[torch.Tensor]          # advantage（0-dim 每样本）
```

### 4.3 `GRPOBatch`（L305）

batch 级 GRPO loss 计算所需数据（collate 后）：

```python
@dataclass
class GRPOBatch:
    completion_mask: torch.Tensor          # [B, T] 响应 token mask
    truncated_mask: torch.Tensor           # [B] 是否截断
    seq_lengths: torch.Tensor              # [B]（padding_free 为 [B+n]）
    old_per_token_logps: Optional[torch.Tensor]   # [B, T] 旧策略 logp
    ref_per_token_logps: Optional[torch.Tensor]   # [B, T] ref logp
    rollout_per_token_logps: Optional[torch.Tensor]  # 重要性采样（IS/DAPO）
    teacher_per_token_logps: Optional[torch.Tensor]  # OPD-RL teacher logp
    advantages: Optional[torch.Tensor]     # [B, T] per-token advantage
    num_items_in_batch: Optional[torch.Tensor]
    logits_to_keep: Optional[int]
    # to_device(device) 方法 (L328): Ray 场景 CPU→GPU
```

### 4.4 `GKDSample` / `GKDBatch`（L338/L344）

- `GKDBatch.data_source`：STUDENT / TEACHER / DATASET 三源标记；
- `teacher_topk_logprobs / teacher_topk_indices`：teacher-API 模式 top-k。

## 5. 数据流转总览

```text
原始数据集 (JSONL / ModelScope / HF)
    ↓  RowPreprocessor 系列
标准行 dict (messages/images/videos/...)
    ↓  template.encode
编码样本 dict (input_ids/labels/loss_scale/...)
    ↓  LazyLLMDataset / PackingDataset
训练 dataset
    ↓  DataLoaderShard / DataLoaderDispatcher (swift/dataloader/)
batch (pad 后张量)
    ├─ SFT: model_inputs + labels → compute_loss
    └─ RL:  rows → OnPolicySample.from_row → rollout → GRPOSample → collate_to_grpo_micro_batch
         → GRPOBatch + model_inputs → _compute_loss_and_metrics
```

### 5.1 RL 数据流的两个关键中转

1. **`collate_to_grpo_micro_batch`**（`swift/rlhf_trainers/utils.py`）：把 `[s.encoded for s in samples]` 拼成 model forward 输入，返回 `(model_inputs, grpo_batch)`。
2. **`get_even_process_data`**：把样本均分到各进程（跨进程 gather 用 `accelerate.utils.gather` / `gather_object`）。

## 7. 一句话总结

```text
配置 → dataclass 多重继承金字塔（BaseArguments → SftArguments → RLHFArguments）
消息 → 纯 dict（role/content/loss/loss_scale）
数据集 → RowPreprocessor 标准化 → template.encode 编码 → Lazy/Packing 打包
RL 样本 → OnPolicySample → GRPOSample（+advantages）→ GRPOBatch（batch 级张量）
```
