## 1. 流式 vs 非流式总览

```text
非流式（默认）:
  load_dataset 全量载入内存
  → 支持按索引 split train/val、shuffle(seed)、PackingDataset
  → 内存占用大，适合中小数据集

流式（--streaming）:
  IterableDataset 边读边用
  → 无法按索引 split（用 take/skip）
  → shuffle 用 buffer
  → IterablePackingDataset 滑动打包
  → 内存占用小，适合超大数据集
```

## 3. 加载链路差异

### 3.1 `DatasetLoader`（`swift/dataset/loader.py` L22）

```text
load_dataset (L224):
  streaming=True → 以 streaming 方式加载（hf_load_dataset streaming）
                   返回 HfIterableDataset（IterableDataset）
  streaming=False → 全量加载
  L318-319: if streaming: num_proc = None（流式禁止多进程预处理）
```

### 3.2 流式 vs 非流式的处理差异（`dataset_meta.py`）

`BaseDatasetLoader` 关键方法：

| 操作 | 非流式 | 流式 |
|------|--------|------|
| train/val 切分 | 按索引 slice | `take` / `skip`（L143-147） |
| shuffle | `dataset.shuffle(seed)` | `dataset.shuffle(seed, buffer_size=...)`（L112-117） |
| 多数据集 | concat / interleave | interleave（prob 采样） |

## 4. 编码与打包

### 4.1 三种后处理路径（`swift/pipelines/train/sft.py` `_post_process_datasets` L125-157）

```python
# L137: 非流式且非 split → LazyLLMDataset（惰性编码，跳过坏样本）
# L139: 打包 → IterablePackingDataset if args.streaming else PackingDataset
# L150: 纯流式（不打包）→ EncodePreprocessor 即时编码
```

### 4.2 打包实现（`swift/dataset/packing.py`）

- `calculate_matched_group`（L16）：打包策略；
  - `binpack`：best-fit-decreasing（最优适配，bin 尽量填满）；
  - `sequential`：next-fit（顺序填）；
- `PackingDataset`（L50）：非流式，`torch.utils.data.Dataset`；
- `IterablePackingDataset`（L137）：**流式打包**，`IterableDataset`：
  - 多进程队列；
  - `packing_interval=128` 滑动打包（攒 128 条再打，减少碎片）；
  - `cyclic` 参数支持循环（打包不满时回绕）。

## 5. DataLoader 层（`swift/dataloader/`）

### 5.1 `DataLoaderShard`（`shard.py` L80）

- 继承 `torch DataLoader`；
- 遍历时把 batch `to_device` 移到指定 device；
- `BatchSamplerShard`（L11）：
  - DDP 分片（`total_samples // world_size`）；
  - 按 rank 切分；
  - 可选 `group_by_length` 长度分组；
  - `set_epoch` 种子递增。

### 5.2 `DataLoaderDispatcher`（`dispatcher.py` L8）

- rank0 主进程负责迭代基础 dataloader；
- 用 `dist.scatter_object_list` 把 batch 分发到各 rank；
- 支持 `skip_batches` 跳过预热 batch（resume 对齐）。

### 5.3 GRPO 场景的采样器

`grpo_trainer.py` `_get_train_sampler`（L175）：

```text
sequence_parallel 时:
  RepeatSampler（每样本重复 num_generations 次，生成批大小 = generation_batch_size // num_generations）
否则:
  super()._get_train_sampler（HF 默认）
```

## 9. 流式调试注意点

| 注意点 | 说明 |
|--------|------|
| max_steps | 流式无限数据集必须设 `--max_steps` |
| split 无效 | `split_dataset_ratio` 流式下自动置 0 |
| shuffle buffer | 调 `shuffle_buffer_size` 控制随机性/内存 |
| 打包碎片 | `packing_interval` 调大减少碎片但增加内存 |
| 多进程 | 流式 `num_proc=None`，预处理在单进程 |
| cached 冲突 | 流式与 `cached_dataset` 互斥 |
| 断点续训 | `skip_batches` 对齐 resume 位置 |

## 10. 一句话总结

```text
流式 = IterableDataset 边读边用 + take/skip 切分 + buffer shuffle + IterablePackingDataset 滑动打包
数据 = JSONL 标准格式 + 注册机制 + IndexedDataset 缓存
DataLoader = DataLoaderShard（DDP 分片）+ DataLoaderDispatcher（rank0 分发）
```
